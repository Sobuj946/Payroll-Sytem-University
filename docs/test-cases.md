# Test cases

Each case has a Test Case ID, Scenario, Preconditions, Input, Expected Result, Actual Result and Status.
All 178 cases are automated (column *Automated test*). Run them with `php artisan test`; then `python3 docs/fill_results.py` fills **Actual Result** and **Status** from the run.
Until the tests have been run, those two columns say *Not run yet*.
